Fret Slot G Code Generator for CNC

Enter you values below. All fields required. The fret slots will be based on the nut width and the width AT the last fret and will not go all the way through. To make frets go all the way through, add a quarter inch or 6 mm to each fret entry (Keeping it even) and the fret slots will be wider. If you use inches, becuase CNC machines like metric, the final output will always be in mm, but it converts for you, so either choose mm and use metric numbers, or select inches and enter inch values. Copy code to a notepad and save as .nc file. Processor is grbl.
