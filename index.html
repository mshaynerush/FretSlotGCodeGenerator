Fret Slot G Code Generator for CNC

Measure your nut where it meets the fret board. Measure the width of the fretboard at the last fret. Enter scale length, how deep you want your slot to be, how much you want the bit to step down, the bit diameter, and the cutting speed. You can use inches or mm. All G-code output will be in millimeters with the conversion being done for you, so if you use inches, just enter the inch values. For CNC that uses Inch values, I will update at a later date. For now, your G-code will be mm so you don't have to do the conversion. Fret slots will not punch through the sides. If you prefer a fret slot that goes all the way through, increase the fret width values by the same amount, 1/4" or 6.35mm (or your own values). Bit starting point is center of the piece at the nut where it meets the fretboard. Copy the code and paste into a notepad, save as type all with the .nc extension. Uses grbl processing. To create a test for your CNC to run a path to verify the behavior, make your step down and your depth of slot the same, set your Z0 to above the fretboard and then you can run the job and see the path it will take. Once you're satisfied with the paths, you can set the dept correctly and the Z0 to the correct start point.
